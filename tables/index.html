🚨 Alertas & Notificações

Diferentes tipos de alerta para comunicar informações importantes ao usuário.

✓
Sucesso
Comprovante validado com sucesso. Este Pix pode ser liberado com confiança.
⚠
Aviso
Este comprovante apresenta sinais de risco. Recomendamos revisar com o cliente antes de liberar o produto.
✗
Perigo
ALERTA: Este comprovante apresenta múltiplos indicadores de fraude. NÃO libere o produto sem verificação manual imediata.
ℹ
Informação
A validação de Pix não substitui verificação manual. Use como camada adicional de proteção contra fraude.
