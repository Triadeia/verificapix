Spacing & Layout

Sistema coeso de espaçamento, grid e responsividade. Baseado em escala 4px para consistência visual.

📏 Escala de Espaçamento

Escala modular de 4px. De --space-1 (4px) até --space-32 (128px). Use para padding, margin e gaps.

4px (1 unit)
--space-1 — Micro gaps, icon padding
8px (2 units)
--space-2 — Tight spacing, borders
12px (3 units)
--space-3 — Buttons, small cards
16px (4 units)
--space-4 — Default padding
20px (5 units)
--space-5 — Component spacing
24px (6 units)
--space-6 — Section padding
32px (8 units)
--space-8 — Large sections, gaps
40px (10 units)
--space-10 — Page padding
48px (12 units)
--space-12 — Main content padding
56px (14 units)
--space-14 — Hero spacing

📱 Breakpoints Responsivos

5 pontos de quebra para mobile-first design. Padrão: mobile primeiro, depois tablet, desktop, etc.

sm (Small)
640px
Dispositivo: Smartphones landscape
Uso: Layout de 2 colunas
Query: @media (min-width: 640px)
md (Medium)
768px
Dispositivo: Tablets portrait
Uso: Sidebar aparece, layout 2-3 colunas
Query: @media (min-width: 768px)
lg (Large)
1024px
Dispositivo: Tablets landscape, laptops
Uso: Layout 3-4 colunas, full sidebar
Query: @media (min-width: 1024px)
xl (Extra Large)
1280px
Dispositivo: Desktop padrão
Uso: Conteúdo max-width 1200px
Query: @media (min-width: 1280px)
2xl (2X Large)
1536px
Dispositivo: Monitores ultrawide
Uso: Layout expansivo com muito espaço
Query: @media (min-width: 1536px)

📦 Container Sizes

Larguras máximas recomendadas por breakpoint para manter conteúdo legível.

Mobile: 100% (full width - var(--space-4) padding)
Tablet (sm): 600px
Desktop (md): 900px
Large (lg): 1200px
XL+: 1400px (com margens)

⬌ Gap Scale (para grids e flex)

Espaço entre itens em grids e flex layouts. Segue a mesma escala do spacing.

gap: var(--space-4) → 16px entre items
gap: var(--space-6) → 24px entre items
gap: var(--space-8) → 32px entre items (padrão para seções)
