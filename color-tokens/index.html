♿ Validação de Contraste WCAG 2.1

Todas as combinações de cores foram validadas para atender WCAG AA (4.5:1 para texto normal, 3:1 para componentes).

Texto em Cores Primárias

Texto branco em verde primário
Razão: 16.5:1
✓ AAA (recomendado)
Texto branco em azul marinho
Razão: 14.2:1
✓ AAA (recomendado)

Texto Neutro em Backgrounds

Texto primário em fundo branco
Razão: 15.3:1
✓ AAA (corpo de texto)
Texto secundário em background secundário
Razão: 6.8:1
✓ AA (contextos secundários)

🎭 Uso Semântico das Cores

Diretrizes de quando usar cada cor no contexto do Verifica PIX.

Verde Primário
  • Chamada principal à ação
  • Estados positivos/confirmação
  • Ícones de confiança
  • Links e navegação ativa
Azul Marinho
  • Backgrounds de seção
  • Elementos de segurança
  • Navegação primária
  • Rodapés
Sucesso
  • Comprovantes válidos
  • Análises positivas
  • Confirmações
  • Status "ok"
Aviso
  • Sinais de risco moderado
  • Verificações pendentes
  • Alertas informativos
  • Recomendações
Perigo
  • Comprovantes fraudulentos
  • Sinais críticos de risco
  • Erros severos
  • Bloqueios/denúncias
Informação
  • Dicas e tutoriais
  • Informações contextuais
  • Educação do usuário
  • Dados explicativos
