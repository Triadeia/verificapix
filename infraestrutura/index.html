06
Infraestrutura técnica — arquitetura completa
🖥️
VPS — servidor principal
MVP · Ativo
Hostinger KVM2 (~R$39/mês) ou Contabo VPS S (~R$25/mês). Ubuntu 22.04 LTS. Roda toda a stack: n8n, Evolution API, Nginx proxy reverso, SSL automático via Let's Encrypt. Para escalar: upgrade vertical do plano VPS — sem migração.
⚡
n8n — motor de automação
MVP · Gratuito
Self-hosted na VPS via Docker. Recebe webhooks do WhatsApp, processa o comprovante com GPT-4o-mini ou Claude, retorna o veredito. Endpoint: api.verificapix.digital/webhook. Custo zero — incluso na VPS. Backup automático dos fluxos no Drive.
💬
WhatsApp — Evolution API
MVP · Self-hosted
Evolution API self-hosted na VPS. Gerencia múltiplos chips/números. Cada cliente vincula seu número via QR Code (como WhatsApp Web). Comprovantes chegam como webhook no n8n. Contingência mínima: 10 chips ativos com rotação automática conforme estratégia da reunião.
🗄️
Banco de dados — Supabase
MVP · Gratuito
Supabase cloud (plano gratuito para MVP). Armazena: clientes, planos, histórico de verificações, status, metadados dos comprovantes e base de dados de fraudadores detectados (CPF, WhatsApp, nome). Row Level Security: cada cliente vê apenas os seus dados. Upgrade para Pro (~R$125/mês) ao escalar.
🎛️
Painel do cliente — no-code
MVP · Low-code
Bubble.io ou FlutterFlow. Hospedado em app.verificapix.digital. Funcionalidades: login, histórico de verificações (data/hora/status), status do plano, configurações do estabelecimento, download do mockup da plaquinha personalizada e alertas de novos golpes.
💳
Pagamentos — Asaas + Stripe
Fase 2
Asaas para cobranças em BRL (boleto, PIX, cartão). Stripe para expansão internacional. Integrado via n8n: plano expirado → bloqueia acesso automaticamente; pagamento aprovado → libera instantaneamente. Modelo: mensalidade recorrente ou pacotes de créditos.
📱
App mobile — FlutterFlow
Fase 2
FlutterFlow — exporta APK (Android) e IPA (iOS) nativos. Android first: Play Store exige apenas US$25 taxa única. App Store (iOS): US$99/ano + aprovação rigorosa de UX. Funcionalidade principal: verificação com câmera (foto direto no app, sem precisar do WhatsApp).
🔗
Árbol de links próprio
MVP · Gratuito
Página simples em links.verificapix.digital. Substitui Linktree — mantém tudo em domínio próprio, mais profissional. Contém: WhatsApp de suporte, Instagram, botão "teste grátis 7 dias", link para o app (futuro), download da plaquinha PDF personalizada.
🔒
SSL, DNS e segurança
MVP · Automático
DNS: Cloudflare gratuito — gerenciamento de todos os subdomínios, proteção DDoS básica, CDN automático e SSL universal (gratuito). Configurar todos os registros A e CNAME lá.
SSL: Let's Encrypt via Certbot — renovação automática a cada 90 dias. Nginx faz o proxy reverso: porta 80 (HTTP) redireciona para 443 (HTTPS). Zero custo.
Backups: VPS com snapshot semanal automático. Banco Supabase com backup diário. Fluxos n8n exportados em JSON e salvos no Drive do projeto semanalmente.
