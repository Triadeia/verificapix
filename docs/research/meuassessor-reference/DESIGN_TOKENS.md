# Reference Design Tokens

Values observed in the live reference at desktop width.

## Reference

- Primary dark surface: near black.
- Main light surface: warm cream `rgb(245, 240, 235)`.
- Body ink: `rgb(26, 26, 46)`.
- Muted text: `rgb(107, 107, 136)`.
- Saturated interruption surfaces: pink and violet.
- Typeface: Poppins.
- Hero heading: approximately 67px, 74px line height.
- Feature heading: approximately 38px, 44px line height.
- Page height: approximately 13,600px.
- Sections: 15.

## Adaptation Rules

- Replace black with Verifica navy.
- Replace pink/violet with Verifica green and pale green.
- Preserve warm, non-pure-white surfaces.
- Use Francy/Sora for brand display and Plus Jakarta Sans for interface text.
- Preserve the long-form rhythm and large product demonstrations.
- Do not reproduce reference assets, testimonials, metrics, prices or copy.
